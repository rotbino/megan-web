# 🛒 iMach (ایمچ) — فرانت‌اند بازار B2B عمده

پروتوتایپ کامل فرانت‌اند **ایمچ (iMach)** — بازار خرید و فروش عمده بدون واسطه، **منطبق بر UX/متن‌ها/مدل داده باسکول** با طراحی مدرن‌تر (سرمه‌ای متمایل به خاکستری، فونت ایران‌سنس).

> **Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · Lucide Icons · TanStack React Query v5**

## وضعیت فعلی (فاز ۱ — پروتوتایپ با دیتای واقعی باسکول)

تمام صفحات کلیدی بازار با **دیتای واقعی گرفته‌شده از APIهای زنده باسکول** پیاده شده‌اند:

| صفحه | مسیر | معادل باسکول |
|---|---|---|
| خانه (هیرو، ۱۰ دسته تصویری، جدیدترین محصولات، جدیدترین درخواست‌های خرید، فرم RFQ، بنر ثبت فروشگاه، کارت‌های سئو) | `/` | صفحه اصلی — ساختار و متن‌ها عین باسکول |
| لیست همه محصولات + جستجو (`?s=`) | `/product-list` | `/product-list` |
| لیست دسته‌بندی + سئو | `/product-list/category/[slug]` | `/product-list/category/پسته` |
| جزئیات آگهی + گالری + چت + قیمت | `/product-view/[slug]/[category]/[id]` | `/product-view/خرید-عمده-پسته/خشکبار/328828` |
| درخواست‌های خرید (RFQ) | `/buyAd-requests` | `/buyAd-requests` |
| پروفایل/ویترین فروشنده | `/profile/[username]` | `/profile/c34qxnsh` |
| ورود/ثبت‌نام با OTP موبایل | `/register` | `/register` |
| پنل فروشنده (داشبورد + جدول آگهی‌ها + نردبان) | `/panel` | پنل باسکول |
| فرم ثبت محصول (دسته آبشاری سه‌سطحی) | `/panel/products/new` | فرم ثبت آگهی باسکول |
| Sitemap + robots + manifest (PWA) | `/sitemap.xml` `/robots.txt` | — |

## دیتای واقعی باسکول (نه ساختگی!)

`src/lib/mock/data.ts` از خروجی واقعی APIهای باسکول تولید شده (اسکریپت: `scripts/gen-mock-data.py` قابل بازتولید):

- **۱۰ دسته سطح ۱** (کشاورزی، خانه و مصالح ساختمانی، فلزات/مواد معدنی/شیمیایی، مد/پوشاک، کیف و کفش، ماشین‌آلات صنعتی، فرآورده‌های غذایی، آرایشی/بهداشتی، لوازم خانگی/الکترونیکی، ورزشی/کادویی) — به ترتیب نمایش صفحه اول باسکول
- **درخت کامل کشاورزی**: ۸ زیرشاخه سطح ۲ + ۸۷ زیرشاخه سطح ۳ با شناسه/واحد/حداقل/امتیاز واقعی (پسته=44، خشکبار=45، خرما=6، سیب=3، زعفران=59، …)
- **۶۰ محصول واقعی** (`user/get_product_list`): پسته/خرما/سیب/زعفران/بادام — با عکس‌های واقعی آبجکت‌استوریج
- **۶۰ درخواست خرید واقعی** (`get_buyAd_list`)
- **۲۶ فروشنده واقعی** (user_info محصولات)

## معماری (ماژولار اما نه افراطی)

```
src/
├── app/                    # صفحات App Router (server components + metadata)
│   ├── layout.tsx          # RTL + فونت IRANSans (محلی) + React Query Provider + SW (پروداکشن)
│   ├── page.tsx            # خانه — عین ساختار باسکول
│   ├── product-list/       # لیست + دسته‌بندی (مرتب‌سازی ۲گانه باسکول)
│   ├── product-view/       # جزئیات آگهی (SEO + JSON-LD)
│   ├── buyAd-requests/     # درخواست‌های خرید (جمله عین باسکول)
│   ├── profile/            # ویترین فروشنده
│   ├── register/           # ورود OTP
│   ├── panel/              # پنل فروشنده + نردبان
│   └── sitemap.ts robots.ts
├── fonts/                  # IRANSansWeb (نسخه محلی — همان فونت باسکول)
├── components/
│   ├── layout/             # هدر (مگامنو + جستجوی زنده) + فوتر (ساختار باسکول)
│   ├── home/               # هیرو، دسته‌های تصویری، ردیف محصولات/درخواست‌ها، RFQ، بنر، سئوکارت
│   ├── products/           # کارت محصول، لیست+فیلتر، چت، مرتبط‌ها، تب‌های پروفایل
│   ├── buy-requests/       # کارت درخواست خرید
│   └── shared/             # نشان‌ها (نردبان/احراز)، قیمت، تصویر محصول، بردکرامب، JSON-LD
└── lib/
    ├── types.ts            # تایپ‌های منطبق باسکول (myuserId, minSalePrice, isLadder, …)
    ├── format.ts           # اعداد/قیمت/تاریخ فارسی (تبدیل تن مثل باسکول)
    └── mock/               # data.ts (دیتای واقعی باسکول) + api.ts + hooks.ts
```

## نکات فنی مهم

- **مدل داده منطبق باسکول**: `src/lib/types.ts` عین فیلدهای API باسکول (`myuser_id`, `sub_category_id`, `min_sale_price`, `min_sale_amount`, `requirement_amount`, …).
- **متن‌ها و اصطلاحات عین باسکول**: جای‌نگاری‌های جستجو/فرم RFQ/دکمه‌ها/جمله کارت درخواست («خریدار X واحد محصول از نوع Y هستم»)/توصیه معامله حضوری — کلمه‌به‌کلمه از باسکول.
- **مرتب‌سازی فقط ۲ گزینه باسکول**: «مرتبط ترین / جدیدترین» — آگهی‌های **نردبان** (تنها قابلیت تبلیغاتی ایمچ v1، ۱۰ هزار تومان در روز) همیشه بالای نتایج.
- **بدون فروشنده ویژه**: `is_elevated` فقط برای مهاجرت داده حفظ شده؛ در UI نشان «نردبان» جایگزین شده است.
- **React Query**: همه دیتا از `lib/mock/hooks.ts`؛ برای اتصال به بک‌اند فقط `lib/mock/api.ts` را با `fetch` واقعی جایگزین کنید.
- **سئو**: SSR کامل + `generateMetadata` داینامیک + JSON-LD (Product, BreadcrumbList, WebSite/SearchAction) + sitemap خودکار. برخلاف باسکول (Vue 2 CSR)، HTML کامل به گوگل می‌رسد.
- **قیمت پشت تعامل**: الگوی Lead-gen باسکول حفظ شده (دکمه «مشاهده قیمت» → دیالوگ کف قیمت + تماس/چت).
- **برندبوک ایمچ**: سرمه‌ای متمایل به خاکستری (جدی/خنثی/کم‌زرق‌وبرق، مناسب B2B) + کهربایی ملایم فقط برای نشان نردبان + لوگوی iMach. توکن‌ها در `globals.css`.
- **فونت ایران‌سنس**: نسخه محلی `src/fonts/` (Regular با اعداد فارسی + Bold woff2) — همان فونت باسکول.
- **PWA + Web Push**: `public/sw.js` (سرویس‌ورکر کاربر) + `manifest.webmanifest` + آیکون‌های `public/icons/` — فقط در پروداکشن ثبت می‌شود.
- **ریسپانسیو کامل** با منوی موبایل و فیلترهای بازشو (بدون سرریز افقی در 390px).

## فازهای بعدی

4. ISR برای صفحات عمومی + optimistic updates
5. چت WebSocket + اعلان‌ها
