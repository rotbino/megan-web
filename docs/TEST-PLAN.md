# سند جامع تست ایمچ (Megan) — نسخه ۲

> **هدف:** تست صفر تا صد تک‌تک صفحات و فرایندهای سایت، پنل کاربر و پنل ادمین؛
> درآوردن لیست باگ، رفع باگ و رسیدن به سیستمی آماده استقرار.
>
> **روش اجرا:** فاز به فاز از «ثبت‌نام» تا آخر. هر تست ✅/❌ + توضیح کوتاه.
> باگ پیداشده → جدول باگ‌ها پایین سند → رفع → تست مجدد.
>
> **تغییرات نسخه ۲ (TEST-F3):** ریشه‌یابی و رفع کامل باگ «ذخیره‌نشدن تصویر آگهی»:
> - قانون «حداقل ۲۰KB» بک‌اند با بهینه‌سازی سمت کلاینت تضاد داشت → کف ۴KB + اعتبارسنجی ابعاد ≥۲۰۰px.
> - خطای آپلود عکس دیگر بی‌صدا گم نمی‌شود → هشدار کهربایی + دکمه «تلاش دوباره ذخیره تصاویر».
> - آپلود عکس حالا مثل بقیه APIها روی 401 توکن را رفرش و تکرار می‌کند.
>
> **نکات پیش از شروع:**
> - بک‌اند روی پورت ۴۰۰۰ (`node dist/main.js`)، فرانت روی پورت ۳۰۰۰ (`next dev`).
> - تست با دو مرورگر/پروفایل جدا: یکی «کاربر عادی»، یکی «ادمین».
> - شماره‌های تست را در بخش «دیتای تست» پایین ثبت کنید تا بین فازها قابل پیگیری باشد.
> - بعد از هر فاز، نتیجه را در همین سند تیک بزنید.
